# Jira Task Description Template

## Background
Why this testing task is required, based on available requirements.

## Objective
The specific testing objective.

## Scope
Features, components, and scenarios to cover.

## Test Activities
- Concrete actions for the assignee.

## Expected Deliverables
- Test definitions, execution evidence, or reports as applicable.

## Acceptance Criteria
- Observable completion conditions supported by the source requirements.

## Dependencies
Relevant environment, build, access, or prerequisite tasks; state `Not specified` if unknown.

## References
Source Jira issues and Confluence pages when available.

> Jira summary, assignee, sprint, epic/parent, and labels are native Jira fields, not substitutes for the description.
